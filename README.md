# MyDemo - 2D 平台跳跃 Demo

Unity 2022.3.62f3c1 · Built-in RP · New Input System

## 操作
A/D 或 ←/→移动 · Z键跳跃 · X键攻击 · C键 冲刺（拾取后解锁）· ↑ 与门交互

## 已实现
- 三场景流程：草原 → 城堡（Boss 关）
- 骑士四态动画 + 攻击/受击/死亡
- 史莱姆巡逻（FSM）+ 猪王 Boss（4 状态、跳砸、受击闪白）
- 血条（5 心）、钻石收集、冲刺解锁、开门切场景、胜利面板
